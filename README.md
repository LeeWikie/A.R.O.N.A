# A.R.O.N.A

让电脑成为什亭之匣，里面住着阿罗娜。

A.R.O.N.A 是一个围绕《蔚蓝档案》阿罗娜构建的个人 AI 伴侣项目，以“什亭之匣的管理者”为角色定位，探索持续陪伴、长期记忆和实际任务执行如何共同形成连续的日常体验。

## 项目方向

- **持续陪伴**：让交流建立在共同经历之上，延续话题、任务和相处习惯。
- **长期记忆**：结合与阿罗娜的对话及接入的用户近期聊天记录，理解近况，保留信息来源。
- **任务执行**：通过 Agent 和工具处理受托事务，并将执行结果与后续交流衔接。
- **多入口交流**：规划 Windows 客户端和独立 QQ 身份，共享连续的经历。

项目尚在开发中，暂未提供可运行版本。
